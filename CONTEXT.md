# Devspace

A single-page portfolio where all site copy lives in one Content Source.

## Language

**Content Source**:
The single place all site copy lives — editing content never touches components.
_Avoid_: config, data file

**Identity**:
The Content Source section describing the site owner (title, bio).
_Avoid_: profile, about

**Hero**:
The full-viewport first section of the page: centered title, bio, CTA pair.
_Avoid_: banner, header

**Skill**:
A technology or competency the site owner lists, with a name, a short blurb, a longer description, and an optional official website.
_Avoid_: technology, stack item

**Project**:
A software work the site owner lists, with a name and a URL to its GitHub README.
_Avoid_: repo, work
